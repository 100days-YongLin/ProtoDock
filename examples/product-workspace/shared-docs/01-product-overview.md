# 产品概述

## 产品目标

- 让内容管理员发布内容，移动端用户查看同一份已发布内容。
- 共享规则只维护一份，各端仍保留独立页面、文档和 Canvas。

## 用户与使用场景

- 移动端用户：查看已发布内容。
- 内容管理员：创建、编辑和发布内容。

## 产品边界

- 本期包含内容查看与内容管理。
- 本期不包含推荐、评论和付费。

## 端与职责

- 移动端：消费内容，不修改发布状态。
- Web 管理端：维护内容并决定是否发布。
- 服务端：保存内容和发布状态，向两个端提供统一口径。

## 成功标准

- 管理员发布后，移动端按约定时效看到相同内容。
- 未发布内容不会出现在移动端。
