# 领域与数据契约

## 术语

- 内容：由管理员维护、可发布给移动端用户的信息单元。
- 发布：内容从草稿变为移动端可见的业务动作。

## 核心实体

- 内容：`id`、`title`、`body`、`status`、`updatedAt`、`publishedAt`。

## 字段与口径

- `status` 仅使用 `draft`、`published`、`withdrawn`。
- `publishedAt` 记录最近一次成功发布时间；未发布时为空。

## 状态机

- 草稿可以发布。
- 已发布内容可以撤回。
- 已撤回内容编辑后回到草稿。

## 数据归属与来源

- 内容与发布状态以服务端数据库为唯一事实来源。
- 前端缓存只用于展示，不得覆盖服务端状态。

## 一致性与生命周期

- 发布成功后，移动端下一次刷新应读到新状态。
- 发布失败不得改变原状态，管理员已填写内容应保留。
