# 跨端流程

## 流程索引

- `FLOW-CONTENT-PUBLISH`：管理员发布内容，移动端用户查看。

## 主流程

### FLOW-CONTENT-PUBLISH

1. 内容管理员在 Web 管理端编辑并提交发布。
2. 服务端校验权限、字段和当前版本后保存发布状态。
3. Web 管理端展示发布成功和权威状态。
4. 移动端刷新列表后读取并展示该内容。

## 状态与事件

- 主状态：`draft -> published -> withdrawn`。
- 发布成功是移动端可见性的唯一触发条件。

## 异常与补偿

- 发布失败：保持原状态和编辑内容，允许管理员重试。
- 版本冲突：拒绝覆盖，要求刷新权威数据。
- 移动端读取失败：保留已有内容并提供重试。

## 跨端验收

### 验收场景 1：发布后可见

- 前提：管理员拥有发布权限，内容处于草稿状态。
- 操作：管理员发布内容，移动端用户随后刷新列表。
- 预期：管理端显示发布成功，移动端展示同一内容和名称。

### 验收场景 2：发布失败不泄漏

- 前提：发布请求失败。
- 操作：移动端用户刷新列表。
- 预期：失败内容仍不可见，管理员输入得到保留并可重试。
