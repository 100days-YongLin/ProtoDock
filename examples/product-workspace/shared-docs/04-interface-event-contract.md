# 接口与事件契约

## 前端职责

- 根据角色展示可用操作。
- 显示加载、空、失败和成功状态。
- 发布失败时保留用户输入并允许重试。

## 后端职责

- 校验身份、权限、字段和状态迁移。
- 持久化内容和发布结果，并返回当前权威状态。

## 接口契约

- 内容列表：返回调用方有权查看的内容及当前状态。
- 发布内容：接收内容标识和客户端已知版本，返回发布后的完整状态。

## 错误与重试

- 网络失败允许重试，不得重复改变业务状态。
- 权限错误提示联系管理员，不提供无效重试入口。

## 幂等与并发

- 同一内容和同一客户端请求标识的重复发布只生效一次。
- 内容已被他人更新时返回冲突，前端提示刷新后重新提交。

## 权限与审计

- 发布与撤回必须记录操作者、时间、内容标识和结果。

## 联调数据

- 至少准备草稿、已发布、已撤回、无权限和版本冲突数据。
