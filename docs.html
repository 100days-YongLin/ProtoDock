ProtoDock 原型舱

用一个工作目录管理画布、PRD 和静态原型。

ProtoDock 读取项目里的 manifest、页面入口和 Markdown 文档，把它们组合成可编排、可预览、可分享的原型工作台。

快速开始

1

准备项目目录

项目根目录需要包含 protodock.project.json，页面入口通常放在 pages/<page-id>/index.html。

2

打开工作目录

在首页选择“新建项目”或“打开已有项目”。本地保存会写回当前工作目录。

3

编排画布

拖拽页面节点、连接锚点、补充右侧 Markdown，形成可演示的产品流程。

项目目录

推荐让原型项目保持简单、可静态打开，方便 Agent 生成页面，也方便 ProtoDock 读取。

prototype-project/
├── protodock.project.json
├── pages/
│   └── home/
│       └── index.html
├── docs/
│   └── home.md
└── assets/

画布协作

画布节点、连线、文本说明和设备壳配置都来自 manifest。页面源码可以由设计 Agent 生成，画布位置属于用户在 ProtoDock 里的排布成果。

先保护画布，再更新页面。

导出脚本和 Agent 默认只能增量合并节点，不能整体重写 canvas.nodes、canvas.edges 或 canvas.notes。

分享预览

部署内置 Python 服务后，可以把 .zip 项目包上传到后端，生成 /s/<share-id> 只读预览链接。

PROTODOCK_PORT=6080 python3 server.py

上传

右上角“分享”支持拖入项目 zip，服务端只解压 manifest、pages、docs 和 assets。

预览

分享链接读取服务端副本，不会写回上传者本地文件，也不会允许浏览者编辑。

下载

进入分享页后，右上角按钮会切换为“下载”，浏览者可以拿到对应项目 zip。

Agent 写入边界

  • pages/**、docs/**、assets/** 可以由 Agent 生成或更新。
  • protodock.project.json 中的 project 和 pages 可以按需更新。
  • canvas.nodes、canvas.edges、canvas.notes 默认视为用户资产，不得整体重写。
  • 写 manifest 前必须先备份到 protodock/backups/。

常见问题

分享页为什么是只读的？

分享页读取的是服务端上传副本，目标是给同事快速浏览方案，不承担多人协作编辑。

页面里的图标和素材每次都要下载吗？

ProtoDock 外壳使用本地 vendored 资源。原型页面自己的素材建议放在项目 assets/ 或页面目录中，用相对路径引用。

安全区数值保存在哪里？

保存在 manifest 的 project.safeAreaEnabled、project.safeAreaTop 和 project.safeAreaBottom 字段里。
