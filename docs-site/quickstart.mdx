## 打开工作台

在仓库根目录启动静态服务：

```bash
python3 -m http.server 4175
```

然后打开：

```text
http://localhost:4175/index.html
```

## 新建项目

点击首页的 **新建项目**，选择工作目录和设备规格。ProtoDock 会在目录中创建最小项目结构，并以 `protodock.project.json` 的 `project.id` 作为唯一项目身份。

新建项目后，可以把这个目录交给 Codex、Claude Code 或其他 AI Agent，让它根据需求生成 `pages/`、`docs/` 和 `assets/`。ProtoDock 会读取 Agent 注册到 manifest 里的静态页面入口，并在画布中预览。

首次协作前，先按 [Skill 安装与文件契约](/ai-agent-skills) 安装 `protodock-canvas` Skill，让 Agent 自动遵守画布保护、静态交付和最终 ZIP 验收规则。

## 打开项目

点击首页的 **打开项目** 后，可以选择三种来源：

- `打开本地项目`：点击选择或直接拖入完整的可编辑项目根目录。根目录下必须直接包含 `protodock.project.json`、`pages/`、`docs/` 和可选的 `assets/`。ProtoDock 会先检查 manifest 声明的全部页面入口与 PRD 文件，再在画布节点中用 iframe 渲染静态页面。这个模式可编辑、可保存。
- `打开产品工作区`：同一个产品有多个端时，仍使用“打开本地项目”，但选择直接包含 `protodock.workspace.json` 的外层工作区。顶部可切换端，左侧显示共享产品文档；每个子项目仍可单独打开。
- `打开公开预览`：从当前服务已有发布项目中选择一个公开预览。新版链接使用 `/s/<product>/<version>`，历史随机 ID 链接仍可打开。
- `从 GitHub 仓库打开`：输入仓库地址和稳定分支或版本 Tag，并可选填写项目路径。服务端会下载该 Git 引用中的 ProtoDock 项目，生成一个公开预览链接。

从 GitHub 打开时，分支或 Tag 必填；项目路径留空表示从仓库根目录读取 `protodock.project.json`。

拖入本地项目时只接受一个文件夹，且 `protodock.project.json`、`pages/` 和 `docs/` 必须属于同一个完整项目根。不要打开 `dist`、完整交付外层、`ProtoDock上传包` 的上级目录或 ZIP 解压外层。若当前浏览器不支持文件夹拖拽，请点击 **打开本地项目** 选择目录。

项目根目录是持续编辑、PRD 更新、变更记录和 Git Diff 的唯一来源。不要在项目内生成 `dist/` 或嵌套的第二份 ProtoDock 项目；发布 ZIP 由 ProtoDock 临时生成，或由 Agent 输出到项目目录之外。

成功打开后，浏览器会记住仓库地址、分支和项目路径，下次自动填入。

## 接入 AI Agent

把需求交给 Agent 前，建议让它先阅读：

- `README.md`
- `DESIGN_AGENT_CONTRACT.md`
- `protodock.project.schema.json`
- 当前项目的 `protodock.project.json`

Agent 负责生成页面和文档，ProtoDock 负责展示和编排这些结果。更完整的协作方式见 [接入 AI 工具](/ai-agent-tools)。

## 保存

点击顶部显示的当前项目名称，可以直接修改项目名称。点击“保存名称”后填写本次更新内容，建议按“用户体验 / 产品调整 / 前后端逻辑”归纳，也可以只写相关栏目或简短说明。名称与一条不带版本号的待发布记录会一并写回 `protodock.project.json`。

点击顶部保存按钮会把画布和文档改动写回当前工作目录。存在修改时，需要填写非空更新内容；三栏结构和项目符号是推荐格式，不会成为保存或发布门禁。内容会追加到 `pendingChanges`，此时不产生版本号。统一发布时再使用发布版本号合并为一条正式 `changelog`。保存名称或其他改动前，如果磁盘上的 manifest 已经被其他工具修改，ProtoDock 会弹出冲突提示，让你选择读取本地变更、覆盖本地文件或取消。

## 复制页面截图

选中页面后，点击右侧标题区的复制按钮，可以复制当前页面 PNG。复制按钮右侧支持切换带设备框或无设备框；无框模式使用项目真实视口尺寸并保留安全区。浏览器无法直接写入图片剪贴板时，ProtoDock 会自动下载 PNG。
