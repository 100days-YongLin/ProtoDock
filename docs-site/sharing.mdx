---
title: 统一发布
description: 一次生成稳定公开预览，并同步到产品分支与版本 Tag。
---

部署内置 Python 服务后，点击右上角 **发布**，可以把同一份 ProtoDock 项目同时发布为公开预览、GitHub 产品分支和版本 Tag。

```bash
PROTODOCK_PORT=6080 python3 server.py
```

## 发布标识

填写 `产品标识` 和 `版本` 后，ProtoDock 会生成固定分享路径、持续更新的产品分支和不可变版本 Tag。

```text
产品标识：pictale
版本：v1
Git 产品分支：project/pictale
Git 版本 Tag：release/pictale/v1
公开链接：/s/pictale/v1
最新版入口：/s/pictale/latest
```

发布弹窗会在提交前同时展示四个目标：当前版本 PRD、持续最新版 PRD、产品稳定分支和不可变版本 Tag。关闭 GitHub 同步时，公开预览仍会发布，GitHub 两项目标会弱化并标记为本次不推送，避免把“公开地址”和“Git 分支”误认为同一个概念。

相同内容可以幂等发布到 `pictale/v1`；版本Tag存在但内容不同时必须使用新版本号。每次成功发布还会把 `/s/pictale/latest` 指向该产品最后一次完整发布成功的版本。旧版随机ID和旧版本分支继续兼容，但新发布不再创建永久版本分支。

发布成功后点击 **复制更新文案**，可以一次复制项目与版本、本次更新内容、当前版本链接、最新版入口、GitHub 当前版本 Tag 和持续最新版分支。发布结果还可以展开逐文件 Git Diff。

## 发送到飞书机器人

发布结果区提供 **发送到飞书机器人** 按钮。点击右侧设置按钮，填写飞书群自定义机器人的 Webhook 并保存；之后每次发布完成，都可以把更新内容、当前版本 PRD、持续最新版和 GitHub 分支作为交互卡片发送到群聊。

Webhook 只保存在项目根目录的 `protodock.local.json`。ProtoDock 会自动把它加入 `.gitignore`，并从发布 ZIP、公开预览、下载包和 GitHub 推送中排除。不要把 Webhook 写进 `protodock.project.json`、页面源码或产品文档。

## 项目包

打开本地项目后，ProtoDock 会自动打包当前目录，手动 ZIP 区域默认折叠；没有目录权限或需要发布其他快照时，再展开并拖入项目 ZIP。ZIP 根目录必须直接包含 `protodock.project.json`、`pages/`、`docs/` 和可选的 `assets/`，不能再套项目名、版本号或交付目录。

ProtoDock 上传 ZIP 是独立的临时发布产物，应生成在完整项目根目录之外。不要在可编辑项目内创建 `dist/`、`完整交付` 或嵌套的 `ProtoDock上传包` 目录，也不要把这些外层目录交给用户作为本地打开目录。用户持续编辑时始终打开原来的完整项目根目录。

服务端会在写入前一次性检查 manifest 中全部 `entry`、`doc`、Canvas、跨页导航、返回桥接和变更历史。缺失文件、错误的归档根目录、重复节点、悬空连线、节点重叠或无效页面目标会显示具体问题并停止发布。

## GitHub 同步

服务端配置固定 GitHub 仓库后，发布弹窗中的 **同步到 GitHub** 默认开启，也可以按次关闭。Commit message 仅在同步开启时必填。

服务端把已校验项目包同步到持久交付工作区，再与 `project/<产品>` 比较并提交Diff，最后原子推送稳定分支和 `release/<产品>/<版本>` Tag。稳定分支禁止强推，Tag禁止覆盖。如果 GitHub 推送失败，服务端会恢复发布前的公开版本。

GitHub 凭据位于折叠的 **GitHub 连接配置** 中。Deploy Key 私钥、GitHub App 私钥和工作目录只保存在服务端，不会进入项目包或公开预览。交付工作区默认是 `.github-work/delivery/`，也可以通过 `PROTODOCK_GITHUB_DELIVERY_DIR` 指定；它由ProtoDock独占，不能人工编辑。

## 预览与下载

`/s/<product>/<version>` 默认进入产品文档式预览页：左侧目录按业务分组快速定位页面，中间并排展示真实 iframe 原型与完整 PRD。原型中的按钮、Tab 和返回操作会联动定位到目标页面章节。

需要查看画布节点、连线和右侧文档时，打开 `/s/<product>/<version>/canvas`；长期入口可使用 `/s/<product>/latest/canvas`。这些入口都是只读画布，不允许浏览者编辑 Canvas、文档或页面信息。

公开预览顶部提供项目包下载和 A4 PDF 下载。项目包接口为 `/api/shares/<product>/<version>/download`；PDF 接口为 `/api/shares/<product>/<version>/pdf`，生成状态在 `/pdf/status` 查询。发布成功后服务端会后台预生成 PDF，并按项目内容哈希复用缓存；生成失败时页面自动退回浏览器打印。

## 高速上传

预览域名上传较慢时，可以给浏览器配置单独的直连上传 origin：

```bash
export PROTODOCK_UPLOAD_ORIGIN=http://100.113.173.18:6080
```

浏览器仍使用当前域名生成公开链接，但项目包优先上传到高速 origin 的 `/api/publish`；连接失败时自动回退当前域名。环境变量只填写 origin，不要附带接口路径。
