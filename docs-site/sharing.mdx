---
title: 分享预览
description: 上传项目 zip，生成只读预览链接。
---

部署内置 Python 服务后，可以把 `.zip` 项目包上传到后端，生成 `/s/<share-id>` 公开预览链接。

```bash
PROTODOCK_PORT=6080 python3 server.py
```

## 上传

右上角 **分享** 按钮支持拖入项目 zip。压缩包根目录可以直接包含 `protodock.project.json`，也可以外层包一层项目文件夹。

服务端只解压：

- `protodock.project.json`
- `pages/**`
- `docs/**`
- `assets/**`

## 预览

`/s/<share-id>` 默认进入独立预览页，适合发给产品、设计或测试同学在手机上直接查看原型。

分享项目会从 `shares/<share-id>/` 读取，不会写回上传者本地文件。需要查看画布节点、连线和右侧文档时，可以打开 `/s/<share-id>/canvas`，这个入口仍然是只读画布，不允许浏览者编辑 canvas、docs 或页面信息。

首页的 **打开项目** 支持从公开预览列表打开已有分享项目，也支持从 GitHub 仓库下载指定分支生成只读预览。GitHub 打开需要填写仓库地址和分支；项目路径留空时默认读取仓库根目录。

## 下载

进入 `/s/<share-id>` 后，顶部下载按钮可以下载该只读项目对应的 zip 包。
